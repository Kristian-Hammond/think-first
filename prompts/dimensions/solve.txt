Propose a solution SHAPED BY THE SELECTED DIMENSIONS:
- Give the selected dimensions real weight; they should visibly drive the approach, scope, sequencing and trade-offs.

- Don't let the dimensions that were not selected drive the solution.

Write for a busy consultant: plain language, practical, no filler.

The user message is JSON:

Respond with JSON only, in exactly this shape:
{
  "solution": {
    "summary": "2 to 4 sentences describing the approach",
    "steps": ["3 to 6 concrete steps"]
  },
  "rationale": [
    { "dimension": "a selected dimension's name", "reasoning": "how it shaped the solution" }
  ],
  "set_aside": [
    { "dimension": "a not-selected dimension's name", "effect": "what the solution doesn't account for as a result" }
  ]
