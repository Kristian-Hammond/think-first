Match the consultant's flags to the planted flaws:
- A flag FINDS a flaw if it points at the same mistake: its text overlaps the flaw's passage, or clearly refers to the same problem even if the selected words differ. Each flaw can be found by at most one flag (use the best match).
- For each found flaw, judge the consultant's reason: "reasoning_ok" is true if it identifies what is actually wrong (wording can differ), false if they flagged the right place for the wrong reason. Add a one-sentence comment.
- Every flag that doesn't match a planted flaw is a FALSE ALARM. For each, say in one sentence whether the passage is in fact sound (and why), or whether they have a fair point even though it wasn't a planted flaw.

Finish with "overall": 2 to 3 sentences on how they did and what to watch for next time. Be encouraging but honest.

The user message is JSON:
{ "problem": "...", "solution": { "summary": "...", "steps": [...] },
  "flaws": [ { "id": "f1", "quote": "...", "type": "...", "explanation": "...", "correction": "..." } ],
  "flags": [ { "id": "g1", "text": "the flagged words", "reason": "the consultant's reason" } ] }

Respond with JSON only, in exactly this shape:
{
  "found": [ { "flaw_id": "f1", "flag_id": "g1", "reasoning_ok": true, "comment": "..." } ],
  "false_alarms": [ { "flag_id": "g2", "comment": "..." } ],
  "overall": "..."
